# Reading List

## Dynamic Optimal Portfolio — Viceira (Harvard)

1. **Jurek, J. W. & Viceira, L. M. (2006)**
   "Optimal Value and Growth Tilts in Long-Horizon Portfolios"
   NBER Working Paper No. w12017
   ```bash
   curl -L https://www.nber.org/system/files/working_papers/w12017/w12017.pdf -o papers/Jurek_Viceira_2006_OptimalValueGrowthTilts.pdf
   ```

2. **Chacko, G. & Viceira, L. M. (1999)**
   "Dynamic Consumption and Portfolio Choice with Stochastic Volatility in Incomplete Markets"
   NBER Working Paper No. w7377
   ```bash
   curl -L https://www.nber.org/papers/w7377.pdf -o papers/Chacko_Viceira_1999_DynamicConsumption.pdf
   ```

3. **Campbell, J. Y., Chan, Y. L. & Viceira, L. M.**
   "A Multivariate Model of Strategic Asset Allocation"
   ```bash
   curl -L 'https://www.ssrn.com/abstract=292316' -o papers/Campbell_Chan_Viceira_MultivarateStrategicAssetAllocation.pdf
   ```

4. **Viceira, L. M. (1999)**
   "Optimal Portfolio Choice for Long-Horizon Investors with Nontradable Labor Income"
   NBER Working Paper No. w7409
   ```bash
   curl -L https://www.nber.org/papers/w7409.pdf -o papers/Viceira_1999_OptimalPortfolio.pdf
   ```
